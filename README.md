# Yang Jun — Personal Website

An English-language personal website for Yang Jun, designed around research,
selected work, background, and contact information.

Live site: <https://so1oist9.github.io/>

## Local preview

Start any static file server from the project directory:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## Content to personalize

- `index.html`, hero section: introduction and one-line positioning.
- `#news`: recent updates and announcements.
- `#research`: the three main areas of interest.
- `#work`: real projects, papers, talks, or case studies.
- `#background`: education, professional experience, and other milestones.
- `#contact`: add an email address or other public profiles when ready.

Search `index.html` for `Details to be added` and `Content slot ready` to find
the intentional placeholders.

## Deployment

The repository is published with GitHub Pages from the `main` branch at the
repository root. Push changes to `main` to trigger a new deployment.
